# Hayedo Rural · Proyecto web (UF1841)

Proyecto integrador del certificado IFCD0210. Empresa **ficticia**: todos los datos son inventados.

## Estructura

```
hayedo-rural/
├── index.html          portada (provisional hasta la sesión 4)
├── css/                hojas de estilo (UD4)
├── img/                imágenes y logotipo
├── alojamientos/       fichas de alojamiento (UD3)
└── docs/               documentación de diseño (UD1)
    ├── briefing.md
    ├── analisis-competencia.md
    └── mapa-sitio.md
```

## Cómo trabajar

1. Abre **esta carpeta** en VS Code (*Archivo › Abrir carpeta*), no un archivo suelto.
2. Acepta instalar las extensiones recomendadas (Live Server, Prettier, idioma español).
3. Clic derecho en `index.html` › **Open with Live Server**.
4. Nombres de archivo en minúsculas, sin espacios ni tildes (`casa-los-tejos.html`).

## Normas de uso de la IA

Primero sin IA; después contrasta y anota qué aceptas y por qué. Nunca pegues datos personales reales.
