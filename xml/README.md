# Carpeta xml

1. Instala la extensión **XML** de Red Hat en VS Code.
2. Corrige `ejercicios/errores.xml` (9 errores) en `ejercicios/errores-corregido.xml`.
3. Crea `alojamientos.xml` con los cinco alojamientos del briefing (docs/briefing.md).
4. `ejemplos/actividad-dtd.xml`: ejemplo de DTD interna para conocer la sintaxis (no se entrega).
5. Completa el esquema `alojamientos.xsd` (estructura) y crea `alojamientos-xsd.xml` enlazado a él.
6. Sesión 4: tipos propios en el XSD y los 6 errores de validez de `ejercicios/invalido.xml`.
